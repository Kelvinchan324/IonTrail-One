01 / THE OBJECT

Science equipment
you’ll want to carry.

The long detector tube sets the proportions. Everything else curves around it: a compact screen, simple controls, and a structural loop for a bag or lanyard.

A smoked transparent back reveals the low-voltage electronics and the tube, while a separate opaque guard keeps the high-voltage zone out of reach.

03 / OPEN SDK

Make it
your instrument.

IonTrail One is also a development platform. The Arduino/PlatformIO SDK keeps time-critical pulse counting small and exposes the data customers need to build new experiences.

  • Custom screens, languages and themes
  • Sound, LED and notification behavior
  • BLE services and companion applications
  • CSV/JSON logging and classroom experiments
  • Tube-specific calibration profiles
Open the SDK on GitHub
main.cpp
#include <IonTrail.h>

IonTrailDevice detector;

void setup() {
  IonTrailConfig config;
  config.gmPulsePin = 3;
  config.sampleWindowMs = 10000;
  detector.begin(config);
}

void loop() {
  detector.update();
  if (detector.hasFreshReading()) {
    Serial.printf("%.1f CPM\n",
                  detector.cpm());
  }
}

Important boundary

Curiosity without
false reassurance.

IonTrail One is planned for education and environmental monitoring. It is not a certified personal dosimeter, medical device, contamination survey meter, or proof that an environment is safe. Dose-rate estimates require tube-specific, instrument-level calibration with documented uncertainty.
